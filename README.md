## 🌟 Sobre o Projeto

O **Resenha ON** é uma solução desenvolvida para a Sprint 3 — Web Development com React, como parte do JOVI + FIAP Challenge 2026.

A proposta é transformar a câmera do smartphone JOVI em uma ferramenta inteligente de apoio aos estudos, proporcionando uma experiência rápida, intuitiva e prática para estudantes.

> 📸 Através da tecnologia de **OCR (Reconhecimento Óptico de Caracteres)**, o projeto permite capturar conteúdos presentes em imagens e facilitar sua leitura, organização e utilização no dia a dia acadêmico.

**💡 Nossa Ideia:** Tornar o processo de registrar conteúdos de aula mais rápido, inteligente e acessível.

---

## 🎯 Objetivo

O Resenha ON foi pensado para resolver uma situação comum na rotina de estudantes:

> *"Como registrar e organizar rapidamente uma grande quantidade de conteúdo durante uma aula?"*

Nossa solução utiliza a câmera do smartphone como ponto de entrada para transformar informações visuais em conteúdo que pode ser posteriormente organizado e utilizado pelo estudante.

### 🚀 A experiência busca proporcionar:
* 📷 Captura rápida de conteúdos
* 🔎 Reconhecimento de texto através de OCR
* 📝 Organização das informações
* ⚡ Agilidade durante as aulas
* 📱 Experiência otimizada para dispositivos móveis
* 🎨 Interface simples e intuitiva

## 🚀 Como Executar o Projeto

Quer rodar o Resenha ON na sua máquina? É simples!

### 📋 Pré-requisitos
Antes de começar, certifique-se de ter instalado:
* 🟢 **Node.js**
* 📦 **npm** *(instalado junto com o Node.js)*

### Passo a Passo

**1️⃣ Clone o repositório**  
Abra o terminal e execute:
```bash
git clone https://github.com/1fpz/jovi-resenhaon-sprint3.git
```
*💡 Alternativa: Você também pode baixar o projeto em .ZIP através do botão `Code` → `Download ZIP` no GitHub.*

**2️⃣ Entre na pasta do projeto**
```bash
cd jovi-resenhaon-sprint3
```

**3️⃣ Instale as dependências**
```bash
npm install
```
*📦 Esse comando irá instalar todas as dependências necessárias para executar a aplicação.*

**4️⃣ Inicie o servidor**
```bash
npm run dev
```
*⚡ O Vite iniciará o servidor local de desenvolvimento.*

**5️⃣ Acesse a aplicação**  
Após executar o comando, o terminal exibirá um endereço local (geralmente `http://localhost:5173`). Abra o endereço no navegador e pronto! 🎉
